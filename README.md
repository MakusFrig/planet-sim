Just a recreation of my planet simulation for my IB personal project but with new features and displays (has trails of the moons motion).

It uses the newton equations to simulate the "planets" trajectory

Currently uses a few set "moons" and some random "stars" to orbit and generates frames and GIF files

Knowing how little computing resources were used to put humans on the moon, its a challenge for me to use todays computing to simulate the same launch. 

The next step is to create a program that can automatically calculate how to send a projectile into orbit, launch to the other moons orbit, land, launch, orbit, orbit launch, and re-land on the same planet.
